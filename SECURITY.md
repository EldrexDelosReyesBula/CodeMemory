# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take security vulnerabilities seriously.

### How to Report
- **Do NOT create a public issue on GitHub.**
- Email details to **security@codemem.dev** or use the GitHub Security Advisory private reporting tab.
- Please provide:
  1. A description of the vulnerability.
  2. Steps to reproduce or proof-of-concept code.
  3. Affected versions, Node.js version, and OS.

### Response Commitments
- **Acknowledgment:** Within 24 hours.
- **Triage & Severity Assessment:** Within 48 hours.
- **Fix & Advisory Release:** Within 5 business days for critical vulnerabilities.
